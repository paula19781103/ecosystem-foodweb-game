# 🧬 소화 과정 탐험 게임 (Digestion Adventure)

> 인체의 소화 기관을 탐험하며 영양소가 소화 효소를 만나 단계별로 분해·변신하는 과정을 체험하는 과학 교육용 게임입니다.

---

## 📖 프로젝트 개요

이 게임은 사용자가 직접 영양소(녹말) 캐릭터가 되어 입에서 시작되는 소화 과정을 플레이하며 **소화 효소의 작용과 영양소 분해 단계**를 자연스럽게 익힐 수 있도록 제작되었습니다. 특히 개발 과정에서 발생한 과학적 오류를 **AI 대화형 디버깅**을 통해 직접 검증하고 수정하며 완성도를 높였습니다.

---

## 🎮 게임 주요 기능 및 스테이지 구성

### 스테이지 1: 입 (Mouth)
* **초기 캐릭터:** 녹말 (크기 100%)
* **획득 아이템:** 침 (아밀레이스)
* **변신 규칙:** 침(아밀레이스) 아이템을 먹으면 녹말이 **엿당(크기 50%)**으로 분해·변신합니다.
* **핵심 과학 원리:** 입에서는 녹말이 최종 산물인 포도당까지 분해되지 않고, 중간 단계인 엿당까지만 분해됩니다.

## 🐛 과학적 오류 검증 및 AI 디버깅 기록

게임 테스트 중 발견한 과학적 오류와 해결 과정입니다.

* **발견된 버그(오류):**
  침(아밀레이스) 아이템을 먹었는데, 캐릭터가 `엿당(크기 50%)` 단계를 건너뛰고 바로 가장 작은 `포도당(크기 25%)`으로 변해버리는 문제가 발생함.
* **문제 인식:**
  "입에서는 녹말이 엿당까지만 분해되어야 하는데 과학적 오류가 발생했네!"
* **적용한 대화형 디버깅 프롬프트:**
  > “AI야, 1단계 입 스테이지에서 아밀레이스를 먹었을 때 캐릭터가 바로 포도당으로 변하는 오류가 있어. 크기가 25%가 아니라 50%로 줄어들고, 이름도 '엿당'으로 변신하도록 코드를 수정해 줘.”
* **해결 결과:**
  입 스테이지에서 아밀레이스 획득 시 캐릭터 크기가 50%로 축소되고 이름이 `엿당`으로 정상 변경되도록 로직을 수정함.
